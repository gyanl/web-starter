# web-starter

A tiny starter kit for your very first website. Made for the Tech 1 course.

## What's inside

Only three files matter:

| File | What it does |
| --- | --- |
| `index.html` | The content of your homepage |
| `style.css` | How everything looks |
| `scripts.js` | Interactivity (empty for now) |

`article.html` is a second page, to show how pages link to each other.

## How to use it

1. Press the green **Use this template** (or **Fork**) button at the top of this page to get your own copy.
2. Open your copy in **GitHub Desktop** (Clone repository).
3. Open the folder in **VS Code**.
4. Double-click `index.html` to open it in your browser.
5. Change something in VS Code, save, refresh the browser. That's the whole loop.

## Ideas for what to change first

- Put your actual name in `index.html`
- Change the background color in `style.css`
- Add a new `<li>` to the list
- Break something, see what happens, then fix it
